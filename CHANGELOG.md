## [0.1.0] — 2026-11-17

Первая рабочая версия. Проверена на живой конфигурации:
Windows 11 (build 26300), RTX 3060 Ti, LG 2560×1440 + AOC 1920×1080 + Philips 4K по
15-метровому оптическому HDMI.

### Добавлено

- `MirrorWindow.ps1` — полноэкранное окно-зеркало основного монитора на телевизоре.
  - определение дисплеев по человекочитаемым именам через CCD API
    (`QueryDisplayConfig` + `DisplayConfigGetDeviceInfo`);
  - DPI-awareness, чтобы 4K-телевизор с масштабированием корректно определялся
    как 3840×2160, а не 1280×720;
  - захват кадра `Graphics.CopyFromScreen` по таймеру, вывод с растяжением;
  - защита от второго экземпляра через `%TEMP%\SoftSplitMirror.pid`;
  - закрытие по `Esc`.
- `MirrorDisplay.ps1` — работа с топологией дисплеев:
  - `-Action status` — список активных путей с режимами;
  - `-Action off` — возврат к стандартному «Расширить»;
  - `-Action on` — экспериментальное клонирование (на целевой конфигурации невозможно,
    см. документацию).
- Обёртки: `mirror-on.cmd`, `mirror-off.cmd`, `fix-layout.cmd`.

### Известные ограничения

- Курсор мыши не отображается на телевизоре.
- DRM-контент (Netflix и подобное) может отдаваться чёрным кадром.
- Задержка 30–60 мс, частота по умолчанию 30 fps.
- Нативное мигание телевизора в дежурном режиме не устраняется — это уровень HPD
  (решается настройками ТВ или аппаратными адаптерами).

### Исправлено в ходе разработки

- Неверная раскладка структур `DISPLAYCONFIG_MODE_INFO` (пропущено поле `adapterId`) —
  из-за неё разрешения читались как мусор.
- Отсутствие DPI-awareness — окно занимало четверть 4K-панели.
- Сопоставление GDI-имени и имени монитора через `EnumDisplayDevices` не работало;
  заменено на CCD.

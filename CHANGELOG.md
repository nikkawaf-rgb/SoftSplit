# Журнал изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [0.2.0] — 2026-11-17

Графическая оболочка и быстрый вывод кадра. Программа стала продуктом: настройка мышью,
иконка в трее, автозапуск, отсутствие консольных команд.

### Добавлено

- `SoftSplit.exe` — приложение WinForms (.NET Framework 4.8, установка не требуется).
- Окно настроек: один дисплей — одна строка; роль «Расширить» или «Дублировать» с выбором
  источника, разрешение и способ вписывания для каждого дисплея.
- Иконка в трее: включить/выключить дублирование, настройки, автозапуск, выход.
- Автозапуск через `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
- Настройки в `%APPDATA%\SoftSplit\config.json`, один экземпляр программы.
- Определение «пропавшего» дисплея: при смене раскладки оконные приёмники
  пересоздаются автоматически.
- Аварийная кнопка «Вернуть обычную раскладку» прямо в окне настроек.
- **Курсор мыши в быстром режиме**: форма снимается через GDI, альфа восстанавливается по
  двум фонам (чёрному и белому), курсор рисуется отдельным проходом с альфа-смешиванием.
  Позиция читается через `GetCursorInfo` каждый тик, поэтому курсор двигается даже на
  статичной картинке.

### Изменено

- **Захват кадра переведён на DXGI Desktop Duplication**, вывод — на собственный swap chain
  с шейдером. Процессор больше не участвует в переносе пикселей: нагрузка упала с ~90 %
  одного ядра до 2–3 % при том же разрешении и частоте.
- Старый путь (`BitBlt` + `StretchBlt`) сохранён как режим совместимости: он работает в
  сеансах RDP.
- DPI-awareness переведён на **Per-monitor v2**: окна-приёмники занимают физические
  пиксели дисплея, а не его виртуальную копию.
- Дисплеи определяются по идентификатору устройства, а не по подстроке имени.
- Диагностика: `--diagnose`, `--probe-dx`, `--test-cursor`, `--gdi`, `--verbose`.

### Исправлено

- Окно-приёмник создавалось меньше дисплея при масштабировании, потому что WinForms
  пересчитывал его размер по DPI.
- Конфигурация с BOM (например, сохранённая в Блокноте) читалась как пустая.
- Кириллица в консольной диагностике выводилась мусором.

### Известные ограничения

- Защищённый контент (DRM) может отдаваться чёрным кадром.
- Задержка порядка одного кадра, частота по умолчанию 30 fps.

## [0.1.0] — 2026-11-17

Первая рабочая версия: дублирование дисплея на другой дисплей полноэкранным окном,
без изменения раскладки Windows и без потери разрешения.

### Добавлено

- Определение дисплеев по человекочитаемым именам из EDID через CCD API
  (`QueryDisplayConfig` + `DisplayConfigGetDeviceInfo`).
- Полноэкранное окно-приёмник: без рамки, поверх остальных окон, ровно в границах дисплея.
- Захват кадра с дисплея-источника и вывод с масштабированием.
- Защита от второго экземпляра.
- Аварийный возврат к раскладке «Расширить» одной командой.
- Документация: как устроено, ограничения, решение проблем, разработка.

### Исправлено в ходе разработки

- Окно занимало часть дисплея при масштабировании 150–300 % — добавлена работа с
  физическими пикселями.
- Разрешения дисплеев читались как мусор из-за неверной раскладки структур
  `DISPLAYCONFIG_MODE_INFO`.
- Сопоставление GDI-имени и имени монитора через `EnumDisplayDevices` не работало;
  заменено на CCD.

### Известные ограничения

- Курсор мыши не отображается на дисплее-приёмнике.
- Защищённый контент (DRM) может отдаваться чёрным кадром.
- Задержка порядка одного кадра, частота по умолчанию 30 fps.

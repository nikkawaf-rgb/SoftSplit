# Решение проблем

Быстрый справочник: симптом → причина → что делать.

---

## Зеркало не включается

### Окно не появляется, в консоли `ERROR: no display matching 'Philips'`

Скрипт не нашёл телевизор по имени.

1. Телевизор включён и переключён на нужный HDMI-вход?
2. Проверьте, как система называет дисплеи:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\MirrorDisplay.ps1 -Action status
   ```

3. Если имя другое (например `PHL 65PUS`), запустите с параметром:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\MirrorWindow.ps1 -TargetName "PHL"
   ```

4. Если телевизор вообще отсутствует в списке — проблема в кабеле/питании/входе, а не в программе.

### `ERROR: no display matching 'LG'`

То же самое для источника. Задайте `-SourceName` подстрокой реального имени из `status`.

### `ERROR: source and target are the same display`

Подстрока совпала с одним и тем же монитором (например, оба содержат «LG»).
Уточните имена: `-SourceName "ULTRAGEAR"` и `-TargetName "Philips"`.

### `Already running (pid NNNN)`

Зеркало уже работает. Либо используйте его, либо сначала `mirror-off.cmd`.

Если процесс уже убит, а сообщение осталось — удалите залипший PID-файл:

```powershell
Remove-Item "$env:TEMP\SoftSplitMirror.pid" -Force
```

## Окно есть, но картинка не та

### Окно занимает четверть телевизора / смещено в угол

Причина — отсутствие DPI-awareness (в версии 0.1.0 уже исправлено). Если вы модифицировали
скрипт, убедитесь, что вызов `SetProcessDPIAware()` идёт **до** создания форм.

### Картинка растянута непропорционально

Источник и приёмник имеют разное соотношение сторон (например, 21:9 → 16:9). В 0.1.0
используется `StretchImage`. Решение на будущее — вкладка «Letterbox» в GUI
(см. [ROADMAP.md](../ROADMAP.md)).

### Чёрный экран вместо видео (Netflix, Disney+, некоторые плееры)

Это защита DRM: защищённый вывод не копируется GDI. Программно не обходится.
Варианты: смотреть на самом телевизоре через приложение, либо аппаратный сплиттер.

### Курсор мыши на телевизоре не виден

Ожидаемо: `CopyFromScreen` не захватывает курсор. Если нужно — см. ROADMAP (отрисовка
курсора вручную или переход на Windows Graphics Capture).

## Тормозит / дёргается

| Причина | Что сделать |
|---|---|
| 30 fps по умолчанию | В `mirror-on.cmd` заменить `-Fps 30` на `-Fps 60` |
| Высокая нагрузка CPU | Понизить до `-Fps 20`; временно закрыть тяжёлые приложения |
| Низкая частота обновления источника | Убедиться, что LG работает в 165 Гц, а не в 60 |
| Слабый диск/своп | Проверить свободное место на C: |

## Раскладка дисплеев сломалась

Симптомы: телевизор пропал, все экраны сдублировались в 1080p, окна уехали.

```powershell
cmd /c fix-layout.cmd
```

Применяет стандартную топологию «Расширить». Если не помогло — `Win+P` → «Расширить»,
в крайнем случае перезагрузка. Настройки дисплеев Windows хранит в реестре
(`HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers\Configuration`), перезагрузка их
перечитывает.

## Телевизор мигает (исходная проблема)

SoftSplit это **не лечит**: он лишь показывает картинку окном. Мигание — про HPD/EDID.

Порядок действий:

1. EasyLink / HDMI-CEC на телевизоре → **выкл.**
2. `HDMI Ultra HD` для входа с ПК → **Standard** (вместо Optimal).
3. В Windows для этого дисплея: HDR **выкл.**, 8 бит, 60 Гц, RGB — без глубокого цвета.
4. Если не помогло — аппаратно: CEC-блокер, затем EDID-эмулятор/стабилизатор.
   Подробности: [HDMI-INVESTIGATION.md](HDMI-INVESTIGATION.md).

## Проверка «а жив ли процесс»

```powershell
# PID и состояние
Get-Content "$env:TEMP\SoftSplitMirror.pid" -ErrorAction SilentlyContinue
Get-Process powershell | Select-Object Id, StartTime

# текущая топология
powershell -ExecutionPolicy Bypass -File .\MirrorDisplay.ps1 -Action status

# какие режимы предлагает телевизор
# (внешний скрипт, см. историю: EnumDisplaySettings по \\.\DISPLAY3)
```

## Логи

`MirrorWindow.ps1` пишет только в консоль. Чтобы получить вывод в файл:

```powershell
powershell -ExecutionPolicy Bypass -File .\MirrorWindow.ps1 *> mirror.log
```

`Add-Type` при первом запуске компилирует C# — это может занять 1–3 секунды,
это нормально.

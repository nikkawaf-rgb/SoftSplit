# Планы развития

Текущая версия — 0.2.0: графическая оболочка с иконкой в трее, настройка ролей дисплеев и
разрешений, автозапуск, быстрый вывод через видеокарту.

---

## 0.1 — фундамент (готово)

- [x] Дублирование дисплея на другой дисплей без изменения раскладки Windows
- [x] Определение дисплеев по EDID через CCD API, а не по подстроке имени
- [x] Корректная работа при масштабировании 150–300 % (физические пиксели)
- [x] Один экземпляр, корректный старт и остановка
- [x] Аварийный возврат к раскладке «Расширить»

## 0.2 — графическая оболочка (готово)

- [x] Окно настроек: список дисплеев, роль каждого
- [x] Роль «Расширить» и роль «Дублировать» с выбором источника
- [x] Разрешение и масштабирование для каждого дисплея отдельно
- [x] Иконка в трее с контекстным меню
- [x] Автозапуск при входе в систему
- [x] Настройки в `%APPDATA%\SoftSplit\config.json`
- [x] Быстрый режим: Desktop Duplication + swap chain (2–3 % одного ядра)
- [x] Курсор мыши в быстром режиме
- [x] Режим совместимости на GDI как резервный путь
- [x] Диагностика в один запуск (`--diagnose`)

## 0.3 — удобство

- [ ] Глобальная горячая клавиша включения/выключения
- [ ] Профили конфигураций: разные наборы ролей под работу и развлечения
- [ ] Автоподхват нового дисплея: «как только появится — дублировать»
- [ ] Уведомление в трее при потере или возврате дисплея
- [ ] Локализация интерфейса: русский и английский

## 0.4 — качество картинки

- [ ] Форма курсора через `GetFramePointerShape` вместо GDI-захвата (монохромные курсоры
      со «ступенчатым» XOR-контуром)
- [ ] Выбор качества интерполяции
- [ ] Ограничение области захвата (только окно, а не весь экран)
- [ ] Устранение разрыва кадра при быстром движении (vsync-режим)

## 0.5 — производительность и надёжность

- [ ] Автоматическое снижение частоты кадров, когда картинка не меняется
- [ ] Пауза дублирования при работе от батареи
- [ ] Восстановление после смены раскладки сторонними программами
- [ ] Проверка обновлений

## 1.0 — продукт

- [ ] Установщик (Inno Setup) и portable-сборка
- [ ] Подпись исполняемых файлов
- [ ] Скриншоты интерфейса в README
- [ ] Английский README и интерфейс как альтернатива русскому

## Идеи без версии

- Режим «плитка»: показать на приёмнике не весь экран, а выбранное окно.
- Экспорт EDID и списка режимов дисплеев в файл — для отладки кабелей и адаптеров.
- Нативный клон через `SetDisplayConfig` для пар, у которых есть общий режим: нулевая
  задержка там, где это возможно, с автоматическим откатом к оконному режиму.

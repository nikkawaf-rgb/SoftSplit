# Планы развития

Текущая версия — 0.1.0: рабочий скрипт с `.cmd`-обёртками и документацией.
Дальше — графическая оболочка и настройки, которые не надо править в файлах.

---

## 0.1 — фундамент (готово)

- [x] Полноэкранное окно-зеркало основного монитора на ТВ
- [x] Автоопределение дисплеев по именам (CCD API)
- [x] DPI-awareness
- [x] Одноэкземплярность, корректный старт/стоп
- [x] Аварийное восстановление топологии (`fix-layout.cmd`)
- [x] Документация: архитектура, расследование, троблшутинг, разработка

---

## 0.2 — графическая оболочка (следующий шаг)

Цель: запуск мышью, без консоли и без правки файлов.

- [ ] `SoftSplit.exe` (WinForms) с одним окном настроек:
  - [ ] выпадающий список «Источник» (все активные дисплеи с разрешениями);
  - [ ] выпадающий список «Приёмник» (телевизор);
  - [ ] слайдер FPS (10–60) с подписью текущего значения;
  - [ ] большой тумблер «Включено / Выключено»;
  - [ ] индикатор состояния: «работает», «телевизор не найден», «остановлено»;
- [ ] Иконка в системном трее с контекстным меню (Вкл / Выкл / Настройки / Выход);
- [ ] Хранение настроек в `%APPDATA%\SoftSplit\config.json`;
- [ ] Запуск из трея по двойному клику.

**Критерий готовности**: пользователь ни разу не открывает PowerShell.

## Идеи без версии

- Режим «плитка»: показать на ТВ не весь экран, а выбранное окно.
- Профили: разные наборы «источник → приёмник» под кино, работу, VR.
- Интеграция с Sunshine: подсказать, что для стриминга зеркало не нужно.
- Экспорт EDID подключённых дисплеев в файл (для отладки кабелей).
- Автоматическое понижение разрешения при срывах линка (костыль к HPD-проблеме).
